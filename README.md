# codex-collab · Codex 协作方法论（道法术器）

> **用结构降低偏差，用验证确保结果。**

一个把《Codex Cookbook》协作方法论沉淀为可复用资产的 WorkBuddy Skill：帮你把模糊的编码需求，组织成 AI 编码助手（Codex / Cursor / GPT 类）能稳定执行的结构化指令，并支持一键生成可直接复制的提示词。

## 解决什么问题

和 AI 结对编码时，常见三类翻车：

- **失焦**——没给边界，AI 平均用力、顺手重构、改动扩散；
- **失真**——目标/背景/约束说不清，结果和预期有偏差，反复返工；
- **失稳**——口头共识随上下文丢失，改完停在"已经改了"，没有验证闭环。

本 skill 用「道法术器」四层框架系统性应对：

| 层 | 解决什么 | 关键产物 |
|----|----------|----------|
| **道** | 底层判断：为何会失焦、失真、失稳 | 边界、信息密度、文档+验证意识 |
| **法** | 协作组织：把任务组织成可执行链 | 七条原则、**目标→模式→约束→输出→验证** 五段式 |
| **术** | 具体打法：进入局面后怎么出手 | 13 种高频局面卡片（模板 + 误用边界） |
| **器** | 拿来即用：直接复制的提示词 | 4 个组合模板 + 通用补充句 + 2 个专项模板 |

## 快速开始

### 方式一：在对话中自动触发

在 WorkBuddy 中直接描述编码任务，出现以下任一情况时 skill 会被加载：

- 让 AI 写代码 / 改代码 / 修 bug / 设计方案 / 做长期建设；
- 说"**按 Codex Cookbook 的方式**""**用道法术器帮我**""**结构化我的需求**""**给我写个给 AI 的提示词**"；
- 丢来一个模糊任务，需要先收敛边界再动手。

skill 会按固定流程协作：**先收敛边界 → 判断时间尺度与阶段 → 匹配局面打法 → 套模板 → 附误用边界提醒 → 落到验证闭环**。

### 方式二：命令行一键生成提示词

需要 Python 3，无第三方依赖。

```bash
# 1) 查看全部可用模板
python scripts/build_prompt.py list

# 2) 生成"直接开发型"提示词
python scripts/build_prompt.py gen qi2 --goal "修复登录报错" --scope "支付/权限等无关模块" --verify "补登录单测并跑通"
```

输出即填好部分占位符的五段式提示词，剩余 `【…】` 结合真实任务手动补全后，直接粘贴给任意 AI 编码助手即可。

### `gen` 参数说明

```bash
python scripts/build_prompt.py gen <id> [选项]
```

| 参数 | 含义 | 对应占位符 |
|------|------|-----------|
| `--goal` | 目标 / 具体问题 | 替换【具体问题】【某个 bug】等 |
| `--scope` | **不允许扩展到的范围**（排除项） | 替换【无关范围】【范围 B】等 |
| `--verify` | 验证方式（测试 / 验收标准） | 替换【测试 / 最小验证闭环】等 |
| `--constraint` | 额外约束，追加到输出末尾 | — |

> 注意：`--scope` 填的是"**不要碰**"的范围。例如 `--scope "支付模块"` 会生成"不顺手扩展到支付模块"。

### 更多示例

```bash
# Bug 修复：先复现再改
python scripts/build_prompt.py gen shu09 --goal "订单金额计算错误"

# 完整的 Bug 修复型五段式
python scripts/build_prompt.py gen qi3 --goal "导出 CSV 中文乱码" --verify "补充含中文字段的回归测试"

# 技术债挂账，追加一条约束
python scripts/build_prompt.py gen debt --goal "完成报表页改版" --constraint "债务清单写到 docs/tech-debt.md"
```

## 使用建议

- **模板中的 `【…】` 是占位符**，必须结合真实任务补全，空着会导致输出发散。
- 不要对所有任务机械套"计划模式/先诊断"；任务已经明确时直接推进（术 02）。
- 任何输出都要落到**测试 / 最小验证步骤 / 验收标准**，不停在"已经改了"。
- 本 skill 是**协作方法论**，不是编程语法教学；适用于任何支持自然语言指令的 AI 编码助手，与具体语言、框架无关。
